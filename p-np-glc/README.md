# p-np-glc

Source: `P_NP_GLC` working folder (Neo.K, with Aletheia as collaborating editor).

Two parts:

- `00_數學構造狀態機中介層_v1.0.md` + `01_第一輪_...md` through `24_第二十四輪_...md` — the P/NP dual-hypothesis rehearsal series. 24 rounds plus one prerequisite document: `H=: P=NP` and `H≠: P≠NP` are each built to their strongest version and made to attack each other every round, under one shared computational model, resource ledger, and correctness standard. `README_研究索引.md` is the series' own index.
- `P_NP_動態四層閉合框架_啟發式研究提案_v1.0.md` + two handoff documents (`_研究交接與後續實行建議_v1.0.md`, `_GLC優先研究交接與實行建議_v1.0.md`) — the Dynamic Four-Layer Closure Framework (GLC), Neo's own post-round-24 reformulation, plus two rival proposals for what order to pursue it in.

Curated presentation with per-round detail pages: [amral.evemisslab.com/p-np-dual/](https://amral.evemisslab.com/p-np-dual/) and [amral.evemisslab.com/glc-framework/](https://amral.evemisslab.com/glc-framework/).

Files are unmodified from source. Original zip re-bundles (one per round, purely cumulative — each contains the same `.md` files as the round before it plus the new one) are not included here; this repository's own commit history already captures that progression more precisely than parallel zip snapshots would.
