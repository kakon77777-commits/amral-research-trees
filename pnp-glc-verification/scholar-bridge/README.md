(GCC/USRT/USEG/GLC, admission, closure) back into standard complexity-theory terms
and checks where the mapping holds up and where it breaks down.
`AI-7_跨範式映射報告_v1.0.md` is the first mapping pass; `AI-7_盲審對照與橋接報告_v2.0.md`
specifically checks AI-6's (scholar-traditional) verdict against later engineering
progress, item by item. `.freeze.txt` files alongside the `.md` versions are frozen/
locked plain-text copies of the same content -- read the `.md`, the `.freeze.txt` is
there for byte-stable citation.
