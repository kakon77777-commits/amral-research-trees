# artifacts/ (live, unversioned)

The candidate's "current working" artifact set -- `candidate-projection-spec.v0.2.0.json`
and related JSON, plus a `traces/` subdirectory. Unlike the `artifacts-v0.2.X/`
siblings, this directory is not a frozen snapshot of a specific acceptance round; it's
what the candidate's own live tooling reads/writes by default. See `../README.md` for
what these artifacts represent (candidate-projection hashing, trace-to-record
soundness).
