# BSD P5 v0.8 package

This package records an exact local-arithmetic reduction for the rank-$2$ curve $389.a1$ at $p=11$.

Main new result:

$$
u_{\mathrm{loc}}
=
\frac{16}{11}\frac{388}{389}\log_{\omega}(P)
\in\mathbb Z_{11}^{\times},
\qquad
u_{\mathrm{loc}}\equiv4\pmod{11}.
$$

So the good-prime Euler denominator $11^{-1}$ cancels exactly against the first $11$ in the formal logarithm. The remaining P5 obstruction is the normalized complex leading scalar, not local $11$-arithmetic.

This package does not prove BSD and does not prove local descent of the normalized complex leading coefficient.
