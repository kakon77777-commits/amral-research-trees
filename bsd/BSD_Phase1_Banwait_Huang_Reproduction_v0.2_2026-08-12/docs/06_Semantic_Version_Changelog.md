# 06｜Semantic Version Changelog

theorem-producing code必須額外保存「數學語義版本」，不能只看 Git commit。

監控：

1. $p$-isogeny與 $a_3$ gate；
2. $\gcd(d,3N)=1$；
3. BSD$(E,2)$ 是必要條件還是完整 certificate；
4. $E'$ 的 $\Sha[2]$ 驗證；
5. $\mathcal S$ 是 deterministic criterion或 bounded search；
6. testing flags；
7. timeout是 FAIL 或 UNKNOWN；
8. algebraic rank與 analytic rank是否分欄。

原則：

$$
\boxed{
\text{code version}
\neq
\text{theorem semantics version}.
}
$$
