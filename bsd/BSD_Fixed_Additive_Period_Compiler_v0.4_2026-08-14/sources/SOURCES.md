# Primary source manifest

## Fouquet–Wan
Olivier Fouquet, Xin Wan,
*The Iwasawa Main Conjecture for universal families of modular motives*,
arXiv:2107.13726v3.

Corollary 1.10 gives the rank-zero \(p\)-part formula with modular-form period.
Immediately afterwards the authors state that, for elliptic curves, this
period agrees with the Néron period only up to the Manin constant.

## Česnavičius–Neururer–Saha
Kęstutis Česnavičius, Michael Neururer, Abhishek Saha,
*The Manin constant and the modular degree*,
JEMS 26 (2024), 573–637; arXiv:1911.09446v3.

Key source facts:
- introduction: Edixhoven proves \(p\nmid c_\phi\) for additive \(p\ge11\)
  except additive potentially ordinary Kodaira II/III/IV;
- Theorem 1.2 / Theorem 7.2:
  \(c_\phi\mid6\deg\phi\), and \(v_p(c_\phi)\le v_p(\deg\phi)\)
  for every \(p\ge5\);
- the only possible \(3\)-adic +1 error occurs when \(v_3(N)\ge3\) and
  there is no prime divisor congruent to \(2\bmod3\), unless an appropriate
  rational-singularity certificate is known;
- introduction: Cremona computationally verified the Manin conjecture for
  optimal curves up to conductor \(500000\).
