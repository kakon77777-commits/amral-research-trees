# 10｜Revised Witness-Network Theorem Schema

For a full theorem

\[
\forall d\in\mathcal D(E),\quad \operatorname{BSD}(E^{(d)}),
\]

every fixed odd additive bad prime must have a period certificate with scope:

```text
UNIFORM_FAMILY
```

not merely:

```text
THIS_CURVE.
```

## Type U additive prime

Allowed in the general family theorem.

Example:

```text
p >= 11
Edixhoven local safe class
FW H1/H2/H3 PASS
```

## Type I additive prime

Only individually certifiable.

Example:

```text
CNS modular degree PASS for a particular twist
direct computed Manin constant
low-conductor database verification
```

Type-I primes may be used for proving individual twists, but not for a
universal infinite twist-family statement without a separate uniform theorem.
