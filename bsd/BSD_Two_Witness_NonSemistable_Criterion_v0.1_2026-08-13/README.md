# Two-Witness Non-Semistable Criterion v0.1

This package generalizes the explicit 696.e1 theorem note into a reusable sufficient criterion.

- `paper.md`: theorem-style general criterion and proof.
- `meta/two_witness_certificate.schema.json`: machine-readable certificate schema.
- `meta/status.json`: research status and next extensions.
- `prior/`: the explicit 696.e1 theorem note.
