# BSD Witness-Network Finite-Exception Criterion v0.2

This package generalizes the Two-Witness criterion in two directions:

1. valuation-one / power-of-two-gcd hypotheses are replaced by finite
   exceptional-prime routing;
2. fixed odd additive bad primes are allowed through finite Fouquet–Wan
   residual/period certificates.

Key conclusion:

`odd gcd factor != curve rejection`

Instead it creates a finite exception table.
