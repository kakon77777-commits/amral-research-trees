# Data

`calibrator-19a1.json` and `formal-calibration.json` are deterministic producer outputs. `provenance.json` records the source snapshot, reviewed but uncommitted predecessor manuscripts, sources, and remaining research obligations. Numerical residues refer to the recorded modular-symbol periods, not an unstated Neron-period identification.

The original `provenance.json` payload hashes describe **PC-001 at Git commit `002e5d57399bc3d0f10fc8a683adc00077834301`**, including that commit's README versions. They are historical hashes, not a manifest for later README edits.

PC-002 uses `pc002-inputs.json`, `pc002-relative-regulator.json` and `pc002-cup-normalization.json`. The relative-series result contains every production-layer summand; the cup result includes its full matrix in the deterministic kernel basis. `pc002-provenance.json` binds this round's sources and results.
